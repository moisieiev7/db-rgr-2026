# Розрахунково-графічна робота (СУБД PostgreSQL)

**Мета роботи:** Набуття практичних навичок розроблення прикладного консольного застосунку мовою Python, що взаємодіє з реляційною базою даних PostgreSQL засобами параметризованих SQL-запитів, коректно обробляє помилки та організований за шаблоном MVC.

## Опис предметної області
Предметна галузь — «Наукові експерименти». База даних містить інформацію про дослідників (researchers), експерименти (experiments) якими вони керують, лабораторне обладнання (equipment) та проміжні дані про використання обладнання в конкретних експериментах (experiment_equipment).

## Структура проєкту (MVC)
Проєкт розділено на три логічні рівні:
* **Models (`app/models/`)**: Відповідають за взаємодію з БД (psycopg 3), виконання CRUD-операцій, генерацію даних та пошук.
* **Views (`app/views/`)**: Консольний інтерфейс. Відповідає виключно за вивід меню, повідомлень та форматування результатів пошуку на екран.
* **Controllers (`app/controllers/`)**: Сполучна ланка. Отримує команди від View, викликає відповідні методи у Model та передає результати назад у View.

## Перелік залежностей
* `python 3`
* `psycopg[binary]` (для взаємодії з PostgreSQL)
* `python-dotenv` (для читання змінних оточення)
Повний перелік у файлі `requirements.txt`.

## Інструкція з налаштування та запуску
1. Склонуйте репозиторій: `git clone <URL>`
2. Створіть та активуйте віртуальне середовище:
   `python3 -m venv venv`
   `source venv/bin/activate`
3. Встановіть залежності:
   `pip install -r requirements.txt`
4. Створіть файл `.env` на основі `.env.example` та вкажіть власні параметри підключення до БД (ім'я БД, користувач, пароль).
5. Запустіть програму:
   `python3 main.py`

## Опис меню користувача
1. Переглянути всіх дослідників - Вивід списку з БД.
2. Додати нового дослідника - Внесення даних (INSERT).
3. Видалити дослідника - Видалення даних (DELETE) з обробкою обмежень зовнішніх ключів.
4. Згенерувати тестові дані - Автоматична пакетна генерація даних через `generate_series()` у SQL.
5-7. Пошукові параметризовані запити з відображенням часу виконання у мілісекундах.
